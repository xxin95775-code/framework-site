版本记录

功能、修复与平台支持变化。更新前请先导出项目备份；程序不会删除已有项目数据。

1.4.0当前2026-11

macOS DMG 安装包 · Windows 预览版 · 双语字幕

  • 重新整理本地工作台的信息层级，导入、播放、字幕与项目区域更清晰。
  • 双语字幕支持原文与译文逐条对齐，时间轴回跳，文本复制和导出。
  • 官网改为独立产品站：不再检测本地服务、不再通过网页唤起本地应用。
  • macOS 新增 Apple Silicon 原生 DMG：PyInstaller 打包、拖入 Applications 即安装、无需 Python/终端/ZIP。
  • 内置 FFmpeg/FFprobe、Vision OCR helper、MLX Whisper；用户项目与授权保存在独立数据目录。
  • Windows：已通过 GitHub Actions 的 Windows 原生 Runner 构建 x64 安装程序，并在 Windows Server 2022 上通过静默安装、启动、二次启动与卸载保留数据测试；WinRT 画面文字识别与 faster-whisper 已打包。尚未完成 Windows 10/11 桌面功能与 GUI 验收，因此以预览版发布，不标为正式稳定版。
  • macOS 安装包为 ad-hoc 签名，未使用 Developer ID 公证；首次打开如被拦截，请右键选择“打开”。
