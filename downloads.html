macOS 安装

  1. 打开下载的 FRAMEWORK-1.4.0-arm64.dmg。
  2. 把 FRAMEWORK.app 拖入 Applications 文件夹。
  3. 从启动台或「应用程序」打开 FRAMEWORK；首次启动会自动启动本地服务并打开浏览器。
  4. 若系统提示“无法验证开发者”，在 Finder 中右键应用选择“打开”。

需要 Apple Silicon（arm64）与 macOS 12 或更新版本。当前安装包为 ad-hoc 签名，尚未使用 Apple Developer ID 公证。

Windows 安装

  1. 下载 FRAMEWORK-1.4.0-x64-Setup.exe，核对上方 SHA-256。
  2. 双击安装；如出现 SmartScreen 提示，选择“更多信息 → 仍要运行”。
  3. 安装完成后从开始菜单打开 FRAMEWORK，应用会启动本地服务并打开默认浏览器。

该包由 GitHub Actions 的 Windows 原生 Runner 构建，已在 Windows Server 2022 x64 上通过静默安装、启动、二次启动与卸载保留数据测试；尚未完成 Windows 10/11 桌面功能与 GUI 验收，故标记为预览版，不是正式稳定版。安装包未做代码签名。
